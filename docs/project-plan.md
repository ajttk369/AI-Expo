# AI Future Expo 2026 Project Plan

## Overview

AI Future Expo 2026은 미래 AI 기술 전시회를 가정해 제작한 반응형 홍보 웹사이트입니다. 단순한 랜딩 페이지가 아니라 관람객이 전시 정보를 탐색하고, 기술 상세 페이지를 확인하고, 참가기업과 티켓 정보를 함께 볼 수 있는 전시 플랫폼 형태로 구성했습니다.

## Goals

- 전시회의 브랜드 인상을 첫 화면에서 명확하게 전달한다.
- 기술별 상세 페이지를 통해 AI Medical, Robotics, Smart City, Future Device, Mobility, Cyber AI를 구분해서 소개한다.
- 한국어와 영어 전환을 제공해 글로벌 전시회 느낌을 만든다.
- 영상, 썸네일, 인터랙티브 요소를 활용해 AI 전시회다운 경험을 제공한다.
- 모바일 환경에서도 핵심 정보와 주요 CTA가 쉽게 보이도록 구성한다.

## Target Users

- 일반 관람객: 전시 일정, 기술 구역, 티켓 정보를 빠르게 확인하고 싶은 사용자
- 학생 및 크리에이터: 체험형 AI 기술과 Future Device 영역에 관심 있는 사용자
- 기업 및 바이어: 참가기업, 상담 가능 여부, 프로그램 정보를 확인하려는 사용자
- 포트폴리오 평가자: 기획, 디자인, 구현, 배포 과정을 함께 확인하려는 채용 담당자

## Main Features

- 반응형 메인 페이지
- 다국어 전환
- 기술 상세 페이지 6종
- 기술별 한국어/영어 프리뷰 영상
- 참가기업 검색, 필터, 저장 기능
- 티켓 예매 정보 입력 및 티켓 월렛 데모
- AI 방문 어드바이저, 기술 비교, 일정 생성, 안내봇
- Future Device 체험 흐름과 디바이스 선택 인터랙션
- 실제 배포 환경을 고려한 파비콘, 앱 아이콘, manifest 설정

## Design Direction

전체 톤은 어두운 전시장 배경, 시안/블루 포인트 컬러, 고대비 타이포그래피를 중심으로 잡았습니다. AI 기술 전시회라는 주제에 맞춰 이미지와 영상은 미래 기술, 데이터 네트워크, 전시장 공간감이 느껴지는 방향으로 구성했습니다.

UI는 과한 장식보다 정보 탐색에 집중했습니다. 메인 페이지에서는 강한 히어로와 CTA를 먼저 보여주고, 이후 관람객 유형, 기술 구역, 체험 기능, 프로그램, 티켓으로 자연스럽게 이어지도록 배치했습니다.

## Video Production

웹사이트에 포함된 메인 영상과 기술별 프리뷰 영상은 Adobe Premiere Pro와 Adobe After Effects를 사용해 직접 편집했습니다. 기술 페이지에는 한국어/영어 영상 파일을 각각 연결했고, 사용자가 언어를 바꾸면 해당 언어의 영상으로 전환되도록 구현했습니다.

- 한국어 모드: 한국어 자막과 한국어 나레이션 영상 제공
- 영어 모드: 영어 자막과 영어 나레이션 영상 제공
- 기술별 썸네일은 영상 재생 전 프리뷰 커버로 표시

## Implementation Notes

- `index.html`은 메인 마크업 중심으로 유지하고, 스타일과 스크립트는 `styles/main.css`, `scripts/main.js`로 분리했습니다.
- 기술 상세 페이지는 개별 HTML 파일을 유지하되, 공통 데이터와 렌더링 로직은 `scripts/tech-detail.js`에서 관리합니다.
- 기술 상세 공통 스타일은 `styles/tech-page.css`로 분리했습니다.
- 영상과 이미지 경로는 로컬 파일 실행과 Vercel 배포 모두에서 동작하도록 상대 경로를 사용했습니다.
- 접근성 보강을 위해 언어 버튼, 탭, 비교 버튼, 저장 버튼에 상태 속성을 추가하고 주요 모달은 ESC와 배경 클릭으로 닫을 수 있게 했습니다.

## Repository Organization

프로젝트 루트에는 실제 페이지 파일과 배포 설정만 남기고, 스타일/스크립트/이미지/영상/문서는 폴더별로 분리했습니다.

```text
docs/       프로젝트 설명과 화면 캡처
images/     웹 페이지 이미지와 아이콘
scripts/    JavaScript 인터랙션
styles/     CSS 스타일
videos/     메인 및 기술별 프리뷰 영상
```

## Deployment

## Future Improvements

- 실제 참가기업 데이터가 공개되면 참가기업 목록과 부스 정보를 교체
- 실제 전시장 배치도가 확정되면 전시장 맵 섹션 업데이트
- 영상 파일은 장기적으로 Git LFS 또는 외부 영상 호스팅으로 분리
- 티켓 예매는 실제 결제 또는 폼 제출 API와 연동 가능
